# Windows 简约小窗

小窗显示 Codex 版本、兼容性检查结果和配置文件中的模型名称，提供启动、重启、刷新和退出按钮。界面使用 Windows 自带的 WPF，不依赖浏览器、远程页面或额外桌面运行时。

## 启动与切换速度

1. 打开启动器小窗，等待兼容性检查完成。打开小窗和刷新状态均为只读操作。
2. 如果提示已有 Codex 正在运行，先保存工作并从 Codex 菜单正常退出，再点击「刷新状态」。启动器不会接管或结束其他入口打开的 Codex。
3. 点击「启动 Codex」。小窗显示「速度菜单已启用」后，继续使用 Codex。
4. 在 Codex 原生模型菜单中选择 Standard 或 Fast。

小窗中的「配置模型」来自 `CODEX_HOME/config.toml`，未设置 `CODEX_HOME` 时读取用户目录中的 `.codex/config.toml`。该名称不代表当前聊天实际选择的模型。小窗不显示 Key、供应商地址或聊天内容。

「速度菜单已启用」表示本次运行的客户端适配已通过校验，不代表当前聊天已经选择 Fast，也不代表上游已接受 Fast。实际档位与费用仍以服务端记录为准。

## 重启与退出

重启只对本工具启动的 Codex 生效。先等待任务结束并保存工作，再点击「重启 Codex」并确认。启动器请求 Codex 正常退出后重新启动；如果 Codex 未退出，启动器保留窗口并提示手动处理，不会为了正常重启而强制结束进程。

点击「退出启动器」或关闭小窗时，如果本工具启动的 Codex 仍在运行，会提示一并退出。最小化小窗不会结束 Codex。当前版本不提供托盘常驻。

如果小窗或后台进程被外部强制结束，先保存工作并完全退出残留的 Codex，再重新打开启动器。后台连接失效时，工具沿用原有的进程归属检查与失败清理，只处理本工具启动的进程。

## 命令行

源码或便携包可使用以下命令打开小窗：

```console
node src/cli.mjs gui
node src/cli.mjs window
```

`inspect`、`launch`、`verify` 继续保留。`launch` 使用原有控制台会话生命周期；小窗目前只支持 Windows，macOS 继续使用原有入口。

## 本地验证范围

GUI 定向测试覆盖只读初始化、配置摘要过滤、已有进程阻止启动、拥有会话的正常重启、拒绝退出时保留会话、运行连接丢失后的清理、并发操作拒绝、回环桥接认证以及 Windows PowerShell / WPF 解析。测试使用注入的模拟会话，不发送真实 API 请求。

完整的 Codex 菜单和出站档位验收仍使用现有 `verify` 隔离配置与本地模拟接口。GUI 的重启与退出按钮涉及真实进程，不能用当前正在工作的 Codex 会话做无提示测试。
