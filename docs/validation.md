## 中转和上游边界

本次全部请求发往本地回环模拟接口，使用生成的测试 Key，真实上游请求数为 `0`。结果证明原生菜单能控制发出的 `service_tier`，不能据此证明某个中转已透传、上游接受了优先档位或实际延迟降低。

使用自己的中转时，按 README 分别发送 Standard、Fast、Standard 三条小请求，在中转或上游记录中核对档位。当前仅适配 Standard／Fast；Ultrafast 未纳入交付。

## Windows 验证前置检查
